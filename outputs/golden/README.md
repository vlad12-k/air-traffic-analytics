# Golden table inventory, lineage and data-use notes

This file describes only the seven CSVs currently tracked in `outputs/golden/`. It does not include or replace source inputs, canonical local run files, or mixed-source GT7/GT9/GT10 outputs. The table CSVs are data-bearing artifacts; the root MIT licence applies to owner-authored code, not to their source statistics.

## Inventory boundary and verification

- Exactly seven `outputs/golden/*.csv` files are tracked: GT1, GT2, GT3, GT4, GT5, GT6 and GT8. No original AVI0301 CSV, raw source CSV, GT7/GT9/GT10 CSV, or complete source dataset is tracked in this repository snapshot.
- Local `data/raw/` files and local mixed/canonical outputs remain outside the tracked public inventory. Their files and hashes in the source manifest were inspected read-only; no source data or calculations were changed.
- GT1, GT2, GT3 and GT8 were reconstructed from the local CAA route input and compared with their tracked tables: all 36 airport keys per table matched, with zero value mismatches at floating-point tolerance.
- GT4 was compared pair-by-pair with the local CAA input: 1,752 route records → 666 unique airport-country pairs; 666 output rows; zero missing pairs, extra pairs, or passenger-sum mismatches.
- GT5 was compared cell-by-cell with local AVI0105: 77 categories × 11 years = 847 source values; 847 output rows; zero missing/extra/mismatched values after the documented thousands-to-passengers conversion.
- GT6 was compared year-by-year with local SFO source aggregates: 31,339 input rows, 21 output years (2005–2025), and zero domestic/international total mismatches.
- Local output verification does not grant redistribution rights. “Derived” and “aggregated” are lineage descriptions, not licences.
