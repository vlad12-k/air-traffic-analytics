## Requested original screenshots not published

The ZIP originals remain preserved locally and unchanged. The local 26-screenshot inventory is not a public index. No new original screenshots are copied into the tracked gallery by this change.

- **Power BI UK demand/connectivity, UK scenario, Heathrow candidate pages:** author-created analytics are acknowledged. The original captures contain Microsoft Power BI UI plus third-party CAA values. CAA source permission does not clear the screenshot itself; Microsoft's published conditions exclude third-party content and state Microsoft cannot grant rights to content owned by someone else. An original screenshot would need a clearly applicable documented permission/exception covering the interface use and displayed content separately. Otherwise keep these captures local and use the independent vendor-neutral CAA figures above. The new figures retain public source facts but do not claim to reproduce the original interactive dashboard pages.
- **Power BI global pages (executive, global benchmark, global scenario, Dubai detail and global governance):** do not publish. The images include AVI0301/ICAO-linked results with unresolved redistribution rights. A generic interface permission would not resolve that data-rights blocker; obtain authoritative permission for the relevant AVI0301/ICAO material before reconsideration.
- **IBM Cognos semantic model and UK demand/recovery/filter pages:** owner-created report analysis, IBM interface, and (for demand views) CAA statistics. No IBM permission for these specific captures is documented. Resolve the interface issue with applicable written IBM screenshot/UI permission or use independently rendered, rights-cleared source measures; keep any AVI0301-bearing Cognos pages excluded until data rights are established.
- **Other Cognos pages:** global and benchmark views include unresolved AVI0301-derived results; excluded until those data rights and the separate IBM capture terms are cleared.
- **Google Colab ETL:** upload/count details include AVI0301-linked output and Google Colab UI. Do not publish the capture until the displayed data lineage is cleared and applicable screenshot terms permit the use; the redacted copy does not resolve either question.
- **Azure SQL resource screenshot:** original exposed private resource/account infrastructure identifiers; the local redacted copy is an altered Microsoft UI capture. Keep both local until any remaining identifiers are checked and the applicable screenshot terms explicitly allow the altered capture. The new timeline documents the platform stage without disclosing resource details.
- **Azure SQL validation screenshot:** result grid includes data-bearing recommendation/candidate rows and Microsoft UI. Keep local until all displayed values are rights-cleared and applicable screenshot reuse permission is documented.
- **Historical SIPOC image:** it has no visible author/copyright attribution and contains a source/process table rather than a product dashboard. Keep local until the owner confirms authorship or provides a license/permission for that exact diagram. The public timeline is a separate original summary, not a crop or redaction of the SIPOC.
- **IBM watsonx experiment/import captures:** account/source labels were redacted in copies, but IBM UI and CAA model metrics remain. Confirm IBM capture/logo terms and CAA attribution/no-sale conditions; redaction alone is not clearance.

No `.pbix`, `.pbit`, PDF report export, or original dashboard source file was found in the project tree. The new data figures are independent, author-created SVG renderings from outputs already classified as publishable; they do not copy vendor interface elements or use restricted global data.
