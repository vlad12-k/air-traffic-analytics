# Historical screenshot evidence and rights-status inventory

## Scope and method

This records content, provenance, rights and privacy questions for the **26 original PNGs** in `evidence-inbox/Data GitHub Project.zip`; it is not a permission decision or a request to remove any file. Each archive original was inspected read-only with OCR. The owner previously reviewed five selected assets at full resolution for visual suitability: Power BI `02-uk-market-demand.png`, `05b-scenario-uk-site.png` and `07b-candidate-detail-heathrow.png`; Cognos `07-cognos-semantic-model.png`; and the separate redacted Colab derivative. That visual review is not legal clearance. The other 22 archive originals have OCR-level descriptions and have not received full-resolution human review in this assessment. The image-analysis tool was unavailable in this session because its configured model was rejected; therefore this inventory does not claim pixel-level clearance. Screenshot capture dates are not established by the archive. Tiny text, image metadata and image-only marks may be missed.

All 26 originals match byte-for-byte to an existing repository copy by SHA-256. No original was cropped, redacted, replaced, relocated or deleted in this documentation work. The public GitHub `main` branch already contains historical gallery files; status labels below describe individual content/rights/privacy questions, not current GitHub placement and not an instruction to remove or hide evidence. Presence in the repository is not rights clearance.

### Status key

- **CANDIDATE** — no specific data/privacy problem was identified in the available record; this is not a permission or accuracy clearance.
- **CONDITIONAL** — a source-attribution, map, period, lineage or privacy question is recorded; no blanket permission is implied.
- **HOLD** — an item-specific rights, source-lineage or accuracy question remains. The original and current gallery links are preserved; this label is not a deletion or history-rewrite instruction.
- **LOCAL-ONLY** — the original has an account/infrastructure privacy flag. Some exact copies are already publicly tracked; this label describes the concern and need for an owner decision, not a claim that the file is currently private.

## Per-image status interpretation

The flags above are **content-specific, not platform-wide**. Some Cognos/Power BI screenshots document model or process design without data rows; the Colab original shows a connection template and needs credential/data-content review; UK-only Power BI pages use CAA-derived measures; Azure and watsonx images expose account/infrastructure context; and global pages display AVI0301-associated values with unresolved source lineage/rights. The existing images and links are retained. These flags do not mean that all vendor-interface screenshots are prohibited, and they do not clear any specific image for additional reuse.[2][3][7]

The CAA Table 12.1 comparison is May 2022 versus May 2021, while the Power BI UK-demand and Cognos demand screenshots visibly label 2020 versus 2022; preserve those pixels and correct the surrounding documentation, not the original images.[12] DataSF identifies PDDL for the SFO dataset, but that permission does not clear other content in mixed screenshots.[6][14]

**This inventory neither grants rights nor authorizes a commit, push, or new publication.** It also does not recommend removing current public evidence. The public repository already contains screenshots with account/infrastructure metadata and AVI0301-associated results; the owner should make a separate decision about those specific existing exposures. A disclaimer alone does not resolve them. No source or screenshot file was changed by this documentation work.
