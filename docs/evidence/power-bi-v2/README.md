- [Semantic Model Overview](powerbi-v2-08-semantic-model-overview.png)
- [Relationships Overview](powerbi-v2-09-relationships-overview.png)

They were verified pixel-identical to the audited originals, contain no third-party data rows or identifiable person, and are shared under Microsoft's published screenshot guidance. Required attribution: **“Used with permission from Microsoft.”**

The other nine report-page screenshots remain local-only; no new Power BI capture is added to Git by this update. Four UK CAA-based pages are conditional: they contain source data covered by CAA attribution/no-resale terms, but the original captures also contain Microsoft UI and are not cleared under the documented default screenshot conditions. The original global pages remain not cleared because AVI0301/ICAO-derived results are present.
