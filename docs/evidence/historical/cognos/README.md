# Historical IBM Cognos evidence

For the complete inline gallery and per-screenshot walkthrough, see [all eight original screenshots and technical notes](technical-notes.md).

Per the project owner, they personally created the Cognos reports, semantic model and analysis; IBM Cognos was the reporting platform, not the report author. All eight originals remain linked in the current working tree. The per-image inventory records individual evidence, rights, period and privacy questions; it does not remove or hide existing gallery links:

- [Semantic model](historical-cognos-07-semantic-model.png) — schema/model metadata, no source rows observed.
- [UK demand filter](historical-cognos-11-demand-filter.png) — filtered UK report with CAA-derived passenger measures; cite CAA Table 12.1 and do not sell/resell the data.[4][12]
- [UK demand recovery](historical-cognos-10-demand-recovery-original.png) — ten-airport two-period comparison; all displayed passenger pairs match preserved GT1 CAA-derived output for May 2022 vs May 2021.[4][12]
- [Executive summary](historical-cognos-08-executive-summary-original.png) — combined UK/global ranking, map, SFO and recovery views.
- [Executive filter state](historical-cognos-09-executive-filter-original.png) — selected-airport interaction in the executive pack.
- [Operational monitoring](historical-cognos-12-operational-monitoring-original.png) — airport KPIs, recovery, operational-risk and composite-score views.
- [Operational filter state](historical-cognos-13-operational-filter-original.png) — selected-Heathrow operational view.
- [Risk ranking](historical-cognos-14-risk-ranking-original.png) — populated airport comparison table with passenger, route, recovery and score fields.

CAA attribution/no-sale conditions apply to CAA-derived content.[4]

The semantic-model view is a non-data candidate; global and operational images are held pending AVI0301/ICAO rights or lineage resolution.[2][3]

The demand images are held for the period-label mismatch.[12] The per-image [release inventory](../../screenshot-release-inventory.md) governs future use. Cognos UI alone is not a reason to exclude an image; no IBM endorsement is claimed. Existing gallery links and owner authorship are not rights clearance for embedded data.
